· Все числа получены расчётным ядром, воспроизводимы командой
`python -m fuelcontour run --scenario <id> --plan results/plan_recommended.json`.

## Обоснование: сохраняются ли решения между сценариями

**Инвестиционные и контрактные решения плана сохраняются для стандартного и
стрессового сценариев** (ZBO-модернизация 2036, опционы Earth-New и ISRU 2037).
Причина: стресс — это тот же спрос +15% с 2038, и заложенный запас мощности
(диверсификация + лунная добыча) его покрывает без изменения инвестиций. Менять
контрактную архитектуру между base и stress не требуется — это и есть устойчивость.

**Для низкого и высокого спроса решения по объёмам заказа корректируются, а
инвестиционный каркас — нет:**

- **Низкий спрос.** Инвестиции и резервы те же, но заказы избыточны → склад
  переполняется (123–380 т при ёмкости 120). Корректировка: снизить объёмы отбора и
  часть резерва. Инвестиции ISRU/ZBO остаются оправданными (дешёвое топливо и низкие
  потери выгодны и при низком спросе). Вывод: **каркас сохраняется, объёмы вниз.**
- **Высокий спрос.** Инвестиции те же, но пиковой мощности не хватает: общий сервис
  падает до 84%. Критический при этом держится 100%. Корректировка: добрать
  аварийный канал Emergency в пиковые годы и/или увеличить резерв Earth-Flex.
  Вывод: **каркас сохраняется, добавляется гибкая/аварийная мощность на пик.**

## Что показывает сравнение

1. **Диапазон расходов узкий** (11 851–12 483 млн у.е., ±2,7% вокруг стандартного) —
   решение экономически устойчиво к вариации спроса.
2. **Критический сервис = 100% везде** — приоритетные потребители защищены в любом
   исходе.
3. **Риск при низком спросе — переплата и переполнение**, не дефицит. Управляется
   снижением заказов (обратимо, без потери инвестиций).
4. **Риск при высоком спросе — нехватка пиковой мощности** по некритической части.
   Управляется аварийным каналом.
5. **Обязательный стресс пройден**: критика 100%, общий проседает только в 2039–2040
   и показан честно.

## Как воспроизвести

```bash
python -m fuelcontour run --scenario low      --plan results/plan_recommended.json
python -m fuelcontour run --scenario standard --plan results/plan_recommended.json
python -m fuelcontour run --scenario high     --plan results/plan_recommended.json
python -m fuelcontour run --scenario stress   --plan results/plan_recommended.json
python -m fuelcontour compare --plan results/plan_recommended.json   # base vs stress
```
