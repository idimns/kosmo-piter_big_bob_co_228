# Презентация продукта

Автономная презентация «Топливный космоконтур» — один HTML-файл, ничего
устанавливать не нужно.

## Как открыть

Дважды кликните `index.html` (откроется в браузере). Либо перетащите файл в окно
браузера.

## Управление

- **Стрелки ←/→**, PageUp/PageDown, пробел — переключение слайдов.
- **Home / End** — первый / последний слайд.
- **Кнопки внизу** — «Назад», «Вперёд», точки-индикаторы, счётчик.
- **«На весь экран»** (или клавиша `f`) — презентационный режим.

12 слайдов: проблема, решение, архитектура, рабочее место, стратегия,
стресс-тест, оптимизация, риски, импорт, надёжность, итог.
